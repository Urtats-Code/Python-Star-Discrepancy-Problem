# Plan: Implement Visualize Class for HDF5 Logs

## Objective
Create a `Visualize` class in a new `Visualize.py` module capable of parsing `.h5` files generated by the `GenerationLogger` and producing heatmaps, fitness plots, and animations of the EDA process.

## Key Files & Context
- `Visualize.py` (New): Will house the `Visualize` class.
- `GenerationLogger.py` (Context): Defines the schema of the `.h5` logs.

## Implementation Steps

### 1. File and Class Creation
- Create `Visualize.py`.
- Import necessary libraries: `h5py`, `numpy`, `matplotlib.pyplot`, `matplotlib.animation`.
- Define the `Visualize` class.

### 2. Implement Data Parsing
- **`parse(h5_path: str) -> dict`**:
  - Open the file using `h5py`.
  - Read the `metadata` group into a dictionary.
  - Iterate through all groups starting with `generation_`.
  - Extract and store:
    - `dsm`: The $n \times n$ doubly stochastic matrix for that generation.
    - `best_fitness`: The tracked best fitness up to that generation.
    - `generation_index`: Ensure data is ordered correctly.
  - Return a dictionary containing the extracted time-series data.

### 3. Implement Static Plotting
- **`plot_fitness(data: dict)`**:
  - Line plot of `best_fitness` across generations.
- **`plot_best_dsm(data: dict)`**:
  - Heatmap (using `plt.imshow` with 'viridis' colormap) of the final generation's `dsm`.
- **`plot_dsm_with_fitness(data: dict)`**:
  - A single figure with `1x2` subplots.
  - Left: Heatmap of the final `dsm`.
  - Right: Line plot of the `best_fitness` evolution.

### 4. Implement Animations
- **`plot_dsm_history(data: dict, save_mp4: bool = True, filename: str = "dsm_history.mp4")`**:
  - Use `matplotlib.animation.FuncAnimation` to update the heatmap frame-by-frame corresponding to each generation.
  - Provide functionality to both `plt.show()` and `anim.save(filename, writer='ffmpeg')` if `save_mp4` is true.
- **`plot_dsm_with_fitness_history(data: dict, save_mp4: bool = True, filename: str = "dsm_fitness_history.mp4")`**:
  - Create a `1x2` subplot layout.
  - Left: Heatmap updating per frame.
  - Right: Line plot of fitness up to the current generation (or a full line with a moving marker).
  - Use `FuncAnimation` and support displaying and saving to MP4.

## Verification & Testing
- Ensure `matplotlib` and `ffmpeg` (for MP4 saving) are considered in the environment (may require a note if user doesn't have ffmpeg installed locally).
- Create a short test script or main block within `Visualize.py` to parse an existing log file and generate the visual outputs to verify correctness without errors.
